- Realinho, V., Martins, M. V., Machado, J., Baptista, L. (2021). *Predict students' dropout and academic success (1.0)* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.5777340
- Companion paper: Realinho, V., Machado, J., Baptista, L., Martins, M. V. (2022). Predicting Student Dropout and Academic Success. *Data*, 7(11), 146. https://doi.org/10.3390/data7110146

Save the file (4,424 students; 34 attributes plus the `Target` column; semicolon-separated) as `data/dataset.csv`, or point the `DATASET_PATH` environment variable to it.
